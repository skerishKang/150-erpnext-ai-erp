# Padiem AI ERP Stabilization Roadmap

- Baseline date: 2026-08-04
- Program EPIC: #145
- Current phase: early ERPNext app/runtime MVP
- Current safe provider: `mock`

## Roadmap Principle

Development order follows evidence and risk, not feature visibility.

```text
Installation proof
→ runtime proof
→ company/row permission
→ metric correctness
→ integration CI
→ persistent audit
→ background execution
→ external AI governance
→ provider staging
→ executive UX
```

## Operations-Ready Milestone

The first operations-ready milestone requires:

- supported version matrix
- repeatable installation
- runtime smoke PASS
- restricted-user and multi-company permission PASS
- metric error and record policy PASS
- integration CI required checks
- backups and rollback documented for any new application DocTypes
- mock provider still safe by default

## External-AI Pilot Milestone

Additional requirements:

- company opt-in
- user authorization
- approved field allowlist
- anonymization or minimization
- secure key storage
- provider contract and deletion terms reviewed
- schema-valid staging result
- persistent run audit
- cost and rate limit
- incident response procedure

## Definition of Done for Every Issue

Each implementation issue should include:

- linked PR
- exact head SHA
- files changed
- tests and commands
- runtime environment when applicable
- permission impact
- external AI call status
- data used: synthetic/anonymized/none
- migration and rollback impact
- known limitations
