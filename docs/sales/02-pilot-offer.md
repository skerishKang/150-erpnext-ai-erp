# Pilot Offer — Padiem AI ERP

## Offer Name

**AI ERP Pilot — "CEO Daily Ops in 15 Minutes"**

## Duration

**4 weeks** (with option to extend by 2 weeks if needed)

## Scope

### What We Deliver

| Deliverable | Description |
|-------------|-------------|
| **ERPNext demo setup** | Cloud-hosted ERPNext instance configured for pilot |
| **Customer master data** | Up to 50 customers, 200 items loaded |
| **Sample quotation flow** | Create, send, track quotations |
| **Sample order flow** | Sales order entry with delivery note |
| **Sample inventory** | Stock tracking with low-stock alerts |
| **CEO daily briefing** | AI-generated daily operations summary |
| **AI quotation draft** | Draft quotation from natural language description |
| **Accountant-ready package** | Monthly document export (CSV/PDF) |
| **Training session** | 2 hours of CEO + staff training (online) |
| **Weekly check-in** | 30 min weekly progress review |

### What We Do NOT Deliver in Pilot

- Full accounting, tax filing, VAT, payroll
- Electronic tax invoice (NTS integration)
- Custom integrations with existing systems
- On-premise installation
- Mobile app
- Custom feature development

## Pilot Process

```
Week 1: Setup & Onboarding
├── ERPNext instance provisioned
├── Customer master data loaded
├── Staff training (2 hours)
└── CEO dashboard access granted

Week 2: Daily Operations
├── Customer starts using ERPNext for quotations
├── AI briefing activated
├── Weekly check-in #1
└── Feedback collection

Week 3: AI Feature Activation
├── AI quotation draft enabled
├── Inventory alerts configured
├── Weekly check-in #2
└── Feature usage review

Week 4: Evaluation & Decision
├── Full operations review
├── ROI assessment
├── Weekly check-in #3 (closing)
├── Pilot outcome report
└── Proposal for full subscription
```
