# Sales Positioning — Padiem AI ERP

## One-Liner

**Padiem AI ERP is an AI-native ERP for Korean SMEs.**

## What We Are

- An **ERP system** with AI built into the workflow
- A managed cloud service that CEOs can access from any browser
- An operations tool: quotations, orders, inventory, deliveries, receivables, and reports
- A system that **reduces CEO time on daily operations from 2 hours to 15 minutes**

## What We Are NOT

| We Are Not | Why |
|------------|-----|
| ❌ A chatbot | Chat is an interface, not the product. We are an ERP first. |
| ❌ n8n / Zapier automation | We do not connect existing tools — we replace the manual ERP process |
| ❌ Accounting software | We prepare data for accountants; we do not file taxes |
| ❌ AI consulting | We sell a product, not a service engagement |
| ❌ Excel replacement | Excel needs manual data entry; we provide structured workflows |

## Target Customer Pain Points

| Pain Point | Padiem AI ERP Solution |
|------------|----------------------|
| CEO cannot see today's sales status quickly | AI daily briefing: 30-second summary |
| Quotation drafting takes 20–30 minutes | AI draft quotation from description: < 2 minutes |
| Inventory status is unknown until someone checks | Automated low-stock alerts |
| Receivables tracking is manual spreadsheet | Receivables dashboard with AI aging summary |
| Accountant requests disorganized receipts/monthly data | Accountant-ready monthly document package |
| CEO wants to understand trends but lacks time for analysis | AI-generated sales trend report |
