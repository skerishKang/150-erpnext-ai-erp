## 1. 제안 배경

### 지금 이 순간에도 반복되는 수작업

대표님, 이런 하루를 보내고 계신 건 아닌지요.

아침에 출근하면 어제 매출이 얼마였는지, 아직 입금 안 된 거래처가 어딘지, 이번 주 납기 건이 뭔지 확인해야 합니다. 담당자에게 물어보고, 엑셀을 열어보고, 이카운트에 로그인해서 이것저것 눌러봅니다. 30분에서 1시간이 그냥 사라집니다.

견적서 하나를 만들려면 고객이 원하는 품목을 확인하고, 단가를 찾아보고, 엑셀에 입력하고, PDF로 만들어서 보냅�니다. 한 건에 20분 이상 걸립니다. 하루에 5건이면 2시간입니다.

재고가 부족한지, 납기가 밀릴지, 미수금이 얼마나 쌓여 있는지는 "누군가 물어봐야" 알 수 있습니다. 대표가 실시간으로 파악하는 건 불가능에 가깝습니다.

### ERP를 쓰는데도 수작업이 남는 이유

이카운트나 다른 ERP를 이미 쓰고 계실 수 있습니다. 하지만 솔직히 말씀드리면, ERP가 있어도 견적서는 엑셀로 만들고, 재고는 직접 확인하고, 미수금은 별도로 정리하고 계신 경우가 많습니다.

ERP는 데이터를 "넣는 도구"일 뿐, 대표가 원하는 "지금 우리 회사 상황을 한눈에 보여주는 도구"가 아니기 때문입니다.

### AI가 답이 되는 조건

AI를 쓴다고 해서 모든 게 해결되는 건 아닙니다. 챗봇에게 "매출 보여줘"라고 물어봐야, 연결할 데이터가 없으면 아무 소용이 없습니다.

**AI가 제대로 작동하려면 ERP 안에서 움직여야 합니다.**

고객 데이터, 품목, 견적, 주문, 재고, 배송, 미수금 — 이 데이터가 ERP 안에 체계적으로 들어 있어야 AI가 요약하고, 초안을 만들고, 위험을 알려줄 수 있습니다.

**Padiem AI ERP는 ERP 바깥에서 돌아가는 AI 챗봇이 아닙니다. ERP 안에서 AI가 작동하는 시스템입니다.**

그래야 대표님이 돈을 낼 이유가 생깁니다.

## 2. 제안 솔루션: Padiem AI ERP

### 한 줄 정의

**ERPNext 기반의 AI 내장 ERP. 중소기업 대표의 매일 업무를 15분으로 줄이는 시스템.**

### 시스템 구성

```
┌─────────────────────────────────────────┐
│           Padiem AI ERP                 │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │        ERP 데이터 레이어         │    │
│  │  고객 · 품목 · 견적 · 주문       │    │
│  │  재고 · 배송 · 미수금 · 입금     │    │
│  └──────────────┬──────────────────┘    │
│                 │                       │
│  ┌──────────────▼──────────────────┐    │
│  │         AI 기능 레이어           │    │
│  │  CEO 브리핑 · 자연어 조회        │    │
│  │  견적 초안 · 미수금 요약         │    │
│  │  배송·재고 요약 · 회계사 자료    │    │
│  └─────────────────────────────────┘    │
│                                         │
│  ERPNext (오픈소스 ERP) + AI 엔진       │
│  클라우드 호스팅 · 브라우저 접속        │
└─────────────────────────────────────────┘
```

### 6가지 핵심 기능

| 기능 | 설명 | 대표가 느끼는 가치 |
|------|------|-------------------|
| **CEO 브리핑** | 매일 아침 현황을 AI가 요약 | "오늘 뭘 확인해야 하는지 1분 만에 안다" |
| **자연어 조회** | "이번 달 미수금 큰 거래처 보여줘" | "검색 조건을 몰라도 데이터를 볼 수 있다" |
| **견적서 초안** | "서울건설에 철근 500미터 견적" | "견적서를 2분 만에 초안으로 만든다" |
| **미수금 요약** | 연체 거래처, 금액, 일수를 한눈에 | "돈이 안 들어온 건 바로 알 수 있다" |
| **배송·재고 요약** | 출하 예정, 재고 부족 품목 표시 | "재고가 부족한지 창고에 가지 않아도 안다" |
| **회계사 자료 정리** | 월말에 회계사에게 보낼 자료 자동 정리 | "엑셀 정리하는 시간이 사라진다" |

## 3. 기존 방식과의 차이

### 비교 표

| 항목 | 엑셀 | 이카운트 등 기존 ERP | 단순 AI 자동화 | Padiem AI ERP |
|------|------|---------------------|---------------|---------------|
| 견적/주문 관리 | 수동 입력 | 기본 제공 | 연결 복잡 | ERP 내장 |
| 재고 추적 | 수동 관리 | 실시간 가능 | 데이터 없음 | 실시간 + AI 알림 |
| 미수금 관리 | 별도 정리 | 목록 확인 가능 | 별도 구축 | AI 요약 + 알림 |
| 대표 현황 파악 | 직접 확인 | 메뉴 탐색 | 불가 | **AI 브리핑** |
| 견적서 작성 | 엑셀 20분 | ERP 입력 15분 | 복잡 | **AI 초안 2분** |
| 회계사 자료 | 수동 정리 | CSV 내보내기 | 불가 | **자동 패키지** |
| 도입 난이도 | 쉬움 | 보통 | 어려움 | 보통 |
| 유지 비용 | 없음 | 월 5~10만원 | 높음 | 월 20~50만원 |

### 왜 "단순 AI 자동화"가 아닌가

챗봇에게 "견적서 만들어줘"라고 말하면, 연결된 데이터가 없으면 AI는 추측밖에 할 수 없습니다.

n8n이나 Zapier 같은 자동화 도구는 기존 도구를 연결하는 방식입니다. 엑셀, 이메일, 메신저를 연결해야 하고, 연결이 끊기면 전체가 멈춥니다.

**Padiem AI ERP는 ERP 안에 데이터와 AI가 함께 있습니다.** 연결할 외부 도구가 없습니다. 데이터가 체계적으로 관리되니까 AI가 정확한 답변을 줄 수 있습니다.

## 4. 4주 파일럿 범위

### Week 1: 업무 흐름 진단 및 ERPNext 데모 환경 구성

- 현재 업무 흐름 인터뷰 (견적 → 주문 → 배송 → 미수금 → 보고)
- ERPNext 클라우드 환경 구성
- 대표님 및 담당자 계정 생성
- 기본 화면 소개 및 교육 (2시간)

**결과물**: 접속 가능한 ERP 환경, 현재 업무 흐름 문서

### Week 2: 고객/품목/견적/주문/재고 샘플 데이터 구성

- 고객 데이터 입력 (최대 50개사)
- 품목 데이터 입력 (최대 200개)
- 창고 구조 설정
- 견적서 → 주문서 → 배송 흐름 테스트

**결과물**: 실제 업무에 사용 가능한 ERP 데이터

### Week 3: AI 브리핑 / 자연어 조회 / 견적 초안 데모

- CEO 브리핑 기능 활성화
- 자연어 조회 기능 테스트
- 견적서 초안 기능 데모
- 미수금 요약 기능 확인

**결과물**: AI 기능이 작동하는 화면, 대표님 피드백 수집

### Week 4: 대표 보고서, 회계사 자료 패키지, 최종 시연

- 배송·재고 요약 기능 확인
- 회계사 자료 패키지 테스트
- 최종 시연 (대표님 + 팀)
- 파일럿 결과 보고서 작성
- 정식 전환 여부 논의

**결과물**: 파일럿 결과 보고서, 정식 전환 제안서

## 7. 기대 효과

### 시간 절감

| 업무 | 현재 | Padiem AI ERP | 절감 |
|------|------|---------------|------|
| 매일 현황 확인 | 1~2시간 | **15분** | 75~87% |
| 견적서 1건 작성 | 20~30분 | **2~5분** | 80~90% |
| 미수금 확인 | 30분~1시간 | **5분** | 83~92% |
| 재고 상태 파악 | 30분~1시간 | **즉시** | 100% |
| 회계사 자료 정리 | 4시간 이상 | **30분** | 87%+ |

### 대표자가 얻는 것

- **아침 15분**으로 오늘 해야 할 일을 파악
- **견적서 초안**을 AI가 만들고, 검토하고 바로 보냄
- **미수금이 쌓이면** AI가 알려주고, 후속 조치 초안까지 제시
- **재고 부족**을 창고에 가지 않아도 확인
- **회계사에게 보낼 자료**를 엑셀로 일일이 정리하지 않아도 됨

### 정성적 효과

- "어제 매출이 얼마야?"라고 물어볼 수 있음
- "이번 주 납기 건有哪些?"를 검색창에 입력하면 바로 확인
- "견적서 초안 만들어줘"라고 하면 AI가 2분 만에 초안 제공
- 엑셀과 이카운트 사이에서 헤매는 시간이 사라짐

## 10. 결론

### 이 사업은 무엇인가

이 사업은 "AI로 ERP를 대체하는 것"이 아닙니다.
이 사업은 "ERP 안에 AI를 넣는 것"입니다.

엑셀에서 이카운트로 넘어갈 때, 대표님은 "데이터를 체계적으로 관리하겠다"는 기대를 하셨을 겁니다. 하지만 현실은 여전히 수작업이 많고, 대표가 원하는 정보를 바로 얻기 어렵습니다.

**Padiem AI ERP는 그 다음 단계입니다.**

ERP 안에 들어 있는 데이터를 AI가 읽고, 요약하고, 초안을 만들고, 위험을 알려줍니다. 대표님은 매일 아침 15분으로 회사 상황을 파악하고, 견적서를 2분 만에 만들고, 미수금을 놓치지 않습니다.

### 첫 파일럿의 목적

첫 파일럿은 "모든 기능을 완성하는 것"이 아닙니다.

**첫 파일럿의 목적은 "대표님이 돈을 낼 만한 가치를 검증하는 것"입니다.**

4주 동안 실제 데이터로 AI ERP를 사용해보시고, "이건 우리 회사 문제를 해결해준다"고 느끼시면 정식으로 전환합니다. 느끼지 못하시면 거기서 멈춥니다.
