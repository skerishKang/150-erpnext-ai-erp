# Non-Goals (First Version)

The first version of Padiem AI ERP does **not** include these features.

## Excluded From MVP

| Feature | Reason |
|---------|--------|
| Full accounting (회계 전산화) | Complex, requires certified accountant validation |
| Tax filing (세무 신고) | Requires government API integration and legal compliance |
| Payroll (급여 처리) | Requires labor law compliance and complex calculations |
| VAT filing (부가세 신고) | Requires 정부24/홈택스 integration |
| Electronic tax invoice (전자세금계산서) | Requires 인증서 and government API |
| Fully autonomous ERP execution | Too risky for first version, human-in-the-loop required |

## Why These Are Excluded

1. **Compliance risk:** Accounting, tax, and payroll require legal accuracy. Mistakes have real consequences.
2. **Complexity:** Each of these is a full product on its own.
3. **Trust building:** We must prove ERP value first before handling sensitive financial operations.
4. **Customer readiness:** SMEs need to trust the system before letting it touch financial filings.

## What We DO Instead

- Prepare **accountant-ready document packages** that the customer's accountant can use
- Provide **sales and receivables views** for business decision-making
- Generate **CEO daily briefings** from operational data
- Handle **operational ERP** (customer, supplier, item, quotation, order, inventory, delivery)

## Future Consideration

These features may be added in future versions after:
- Core ERP is proven and trusted
- Legal and compliance framework is established
- Customer demand is validated
