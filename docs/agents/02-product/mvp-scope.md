# MVP Scope

## Overview

The first version of Padiem AI ERP covers core operational ERP with AI-enhanced workflows.

## Module List

### Core Data Management

| Module | Description |
|--------|-------------|
| Customer management (고객관리) | Customer master data, contact info, transaction history |
| Supplier management (공급처관리) | Supplier master data, purchase history |
| Item management (품목관리) | Product/service catalog, pricing, categories |

### Sales & Purchase

| Module | Description |
|--------|-------------|
| Quotation management (견적관리) | Create, track, and manage quotations |
| Sales order management (수주관리) | Sales order processing and tracking |
| Purchase order management (발주관리) | Purchase order creation and tracking |

### Inventory & Logistics

| Module | Description |
|--------|-------------|
| Inventory status (재고현황) | Real-stock visibility, location tracking |
| Delivery tracking (배송추적) | Shipment status across carriers |

### Finance & Reporting

| Module | Description |
|--------|-------------|
| Sales and receivables view (매출/미수금현황) | Revenue tracking, outstanding payments |
| CEO daily briefing (대표 일일 브리핑) | AI-generated daily business summary |
| Weekly report generation (주간 리포트) | Automated weekly business report |

### AI Features

| Module | Description |
|--------|-------------|
| AI natural-language query (자연어 조회) | Ask questions about business data in Korean |
| AI quotation draft (AI 견적서 작성) | Generate quotations from natural language |
| Accountant-ready document package (회계사 패키지) | Prepare documents for external accountant |

## Total: 14 Modules

## Scope Boundaries

### In Scope
- All modules listed above
- Korean language UI
- Basic reporting and dashboards
- AI integration for listed features

### Out of Scope
- Full accounting (see non-goals.md)
- Tax filing and electronic tax invoices
- Payroll processing
- Multi-currency support (future)
- Multi-language support (future)
